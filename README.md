# 🔄 运营部 · Operations Department

**部长：徐明辉** | 下属：3人（高晓宇、何思雅、曹一鸣）

## 部门定位
公司的运转中枢和保障体系，负责项目管理、流程优化、客户对接、制度维护和行政支持。

## 项目管理流程

```
立项（任务下达）
    ↓
方案制定（资源分配、时间排期）
    ↓
过程跟踪（进度监控、问题协调）
    ↓
交付验收（质量稽核、客户确认）
    ↓
复盘归档（经验总结、统一存档）
```

## 本仓库用途
- 📋 项目排期与进度跟踪
- 📑 流程制度文档管理
- 🤝 客户对接与交付管理
- 📊 运营数据与分析报告
- 📁 公司知识库管理
